# NexEnergy frontend

This directory contains the React + Vite application. Use the root [README](../../README.md) for project setup, local development, environment variables, deployment, and API documentation.

Quick start from this directory:

```bash
npm ci
npm run dev
```

The app uses `http://localhost:8000` for its local backend by default. See the root README to start FastAPI and configure a different API URL.
